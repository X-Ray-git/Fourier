# Android 说明

Android 正在按现有 macOS 设计语言做类比迁移，但不是照搬 AppKit 实现。

平台边界：

- `AppGlassSurface`、`AppGlassCompactSwitch` 等纯 Flutter 组件可以跨平台复用；`NSGlassEffectView`、窗口后方取样和红黄绿等 AppKit 能力仍只属于 macOS。
- 少量固定浮动控件可以使用真实 Flutter 模糊玻璃；时间线卡片等密集重复元素继续使用轻量外壳，避免重演 macOS 列表玻璃造成的性能回退。
- package id 已迁移到 `io.github.xraygit.autofolo`。安装签名 key 不同但包名相同的 APK 会和现有安装冲突；GitHub 内部构建使用已约定的签名设置。

截至 2026-07-18 已完成的迁移：

- 主时间线只在 header 暴露 `未读/全部`，复用 `AppGlassCompactSwitch`。Android 参数为轨道 `55 x 29`、滑块宽 `40`、透明点击区 `48`、外框 `0.6px / 55%`；视觉左边界与卡片统一为 `12px`。
- 底部主导航改为纯图标悬浮胶囊：水平和底部边距 `12px`、高度 `56px`、连续曲率半径 `28px`。该组参数由已验证的底部面板 `8px + 32px` 反推约 `40px` 等效外圆角，并已在当前目标手机上通过视觉确认。外壳固定于 edge-to-edge 内容边界，不再由 `SafeArea` 动态抬高；按钮中心距底边约 `40px`。保留页面淡入淡出和橙色选中反馈，外阴影通过路径差集只绘制在胶囊外侧。
- 最近阅读从主导航移到订阅源页，并作为二级时间线进入。
- 文章页已使用圆形玻璃已读按钮；存在目录时在其上方显示目录按钮，目录使用共享移动端玻璃底部面板。正文底部空间按是否存在目录动态避让。
- 订阅源详情改为紧凑 header，阅读状态筛选与主时间线一致；自动全文、翻译和静默设置进入共享玻璃底部面板。
- `AppMobileGlassSheet` 是移动端玻璃底部面板的共享外壳，当前统一圆角 `32px`、水平边距 `8px`、底部 `viewPadding + 8px`。不要在目录和订阅源设置中分别复制这些参数。
- 普通卡片、骨架、空态继续复用 `ArticleCardChrome` 的布局基线；本轮没有把密集卡片改成重型玻璃。
- 设置页已改为 Android 专用分组布局：页面水平边距 `12px`，大设置面板使用 `24px` 连续圆角和轻量静态外壳；服务认证、阅读偏好、配置迁移、三组 LLM、Prompt 和关于信息按语义分组。正文宽度和 macOS 惯性上限等平台无关项不在 Android 显示。
- Android 设置选择统一通过 `MobileSettingsSelectField<T>`：收起态保持设置输入框外观，点击后打开 `AppMobileGlassSheet`，当前项带勾选，选择即保存并关闭。外观、角标、重试、模型、思考模式、思考强度和 `max_tokens` 均使用该入口；不要重新引入 `DropdownButtonFormField` 的 Material overlay。
- 后台任务中心和 AI 失败记录保持二级页面，而非强行塞回设置列表；它们与设置页共享轻量面板、`12px` 边距和移动端 header。任务实时状态与失败记录仍由原业务控制器负责。
- `MobileBlurAppBar` 是普通 Android 页面共享 header：工具栏高度 `48px`、背景 alpha `0.74`、blur sigma `18`、无分隔线。设置、任务中心、失败记录、最近阅读、垃圾拦截、独立时间线和主 shell 复用它。订阅源详情因头像与双行标题保留专用 `68px SliverAppBar`；文章阅读和全屏媒体保留各自进度/媒体语义，不强行套共享 header。
- 文章动作和图片查看器底部菜单已迁移到共享玻璃面板；搜索、订阅源详情和订阅列表的空态已去掉旧式巨大彩色圆形。文章卡片等高频元素继续保持轻量，不因次级页面迁移增加实时模糊。

已修复的响应式陷阱：

- `SubscriptionsController.unreadFor()` 必须先读取 `_unreadCounts[feedId]`，再根据静默状态决定是否返回零。旧实现对静默源提前返回，导致外层 `Obx` 没有读取任何 Rx：Debug 显示 GetX 红色错误，Release 则表现为 Inbox 展开后从左侧滑入的大块灰色区域。
- 不要把该问题误判为 `AnimatedCrossFade` 或页面淡入淡出故障；为排查做过的替换已经撤销，原有动画保留。

当前边界：

- Android 设计迁移五个阶段已经完成。后续属于真实使用中的局部修正，不再维护“设置页/次级页面尚未迁移”的旧待办。
- 当前底栏同心参数只在目标设备和当前手势导航环境下视觉确认。Android 没有可靠的通用 API 返回物理屏幕圆角；换用明显不同圆角或三键导航的设备时应重新检查，但不要建立按机型硬编码表。

验证清单：

- 主时间线、订阅源详情的 `未读/全部` 筛选正确，左侧与卡片对齐。
- 底部导航三页切换、选中反馈和淡入淡出正常，阴影不污染内部。
- Inbox 展开没有灰色块或 GetX 红色错误。
- 最近阅读入口、文章目录、已读按钮和订阅源设置面板可用，正文不会被浮动控件遮住。
- 深色和浅色模式下控制边界、文字和底部导航均可辨认。
- 设置导入/导出和文章图片预取仍正常。
- 设置页所有选择字段的浮动标签完整，玻璃选择面板不会与背后内容混在一起；选择立即保存。
- 普通次级页面 header 高度统一为 `48px`，正文顶部避让同步，没有残留旧 `56px` 空白。

维护规则：

- 归档只保存旧证据，不追加当前工作日志；当前结论写入专题页或决策日志。
- 一个历史章节只保存在一个主主题，跨主题关系使用链接，不复制原文。
- 单个归档接近 1,000 行时按自然子主题继续拆分，不使用数字文件前缀或机械分卷。
- 旧章节使用稳定的 `legacy-xxx` 锚点；移动章节时必须同步更新 `../chronology.md`。

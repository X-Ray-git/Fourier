# 待办与搁置事项

不要把这里当作必须立刻执行的任务列表。这些是后续可能重新出现的话题。

- 发布：最近一批合并后，用户尚未要求新的 release/tag。
- Worktree 清理：本地可能仍有若干功能 worktree。删除前必须检查，并且只在用户确认后清理。
- 完整 Liquid Glass UI：当前实现是刻意克制的。未来仍可能做更大的 macOS UI 重构，但不要在没有性能验证的情况下重新引入密集重复的重型玻璃效果。
- Android fallback：Liquid Glass 相关功能在 Android 端应保持轻量，不应继承 macOS 专属渲染成本。
- 文章正文虚拟化：文章 scroll 内的 `Column` 仍是有意保留，用于保护选择、目录锚点、图片生命周期和稳定行为。不要随意切换到 `SliverList.builder`。
- macOS 滚动惯性：已有可配置 fling 上限，但更深层的触控板输入过滤因为早期实验效果不佳而搁置。
- 圆角/半径统一：macOS 主几何层第一阶段已做。后续只在用户验证后继续微调，不要盲目全局替换图片、胶囊、小标签或 Android 圆角。
- 旧缓存数据迁移：除非用户要求，一般不做；大多数修复只作用于新拉取数据。
- 文档：后续 agent 应继续维护专题页和决策页，不要重新形成单个巨大的交接文档。

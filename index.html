筛选信息洪流

Auto Folo 将 Folo 时间线、长文阅读和可配置的 AI 工作流放进同一个客户端：后台翻译与摘要帮助快速浏览，垃圾拦截判定进入独立审核页，最终保留或移除仍由你决定。

非官方个人二次开发客户端，不隶属于 Folo、RSSNext 或其运营方。

核心能力

不止于阅读

每一层都经过精心设计，从数据拉取到 AI 决策，形成完整的智能信息处理闭环。

🎯

AI 智能过滤

使用可编辑 Prompt 让 DeepSeek 逐篇给出保留/拒绝建议。被判定为垃圾的文章进入独立审核页，不会绕过用户直接删除。

🌐

自动翻译

按订阅源配置自动翻译，保留 HTML 结构并支持原文/译文切换。模型、思考模式、temperature、输出上限和并发数均可独立调整。

📝

AI 摘要生成

为仍未读的文章生成紧凑摘要，帮助快速判断是否值得点开。文章变为已读后，尚未开始的自动翻译和摘要任务会退出等待队列。

🖼️

长文与图片阅读

HTML 按块渲染，支持文章目录、表格、代码块和 Markdown 复制。图片画廊支持缩放与关闭手势，macOS 可后台预取未读文章中的静态图片。

🎬

视频内联播放

正文可播放直接视频资源与 YouTube 嵌入内容。直接视频支持加载反馈、进度拖拽、键盘控制和全屏播放；不支持的嵌入仍保留安全回退。

📊

订阅源管理

Articles / Social Media / Inbox 按分类和订阅源组织，支持展开、搜索与范围筛选。静默订阅源作为独立分组保留，不干扰普通时间线。

⌨️

macOS 桌面交互

原生分栏与局部 Liquid Glass 适配桌面阅读，配合右键菜单、键盘快捷键、触控板审核和系统窗口行为，避免把移动端页面简单放大。

⚙️

设置与任务状态

选择类设置即时生效，文本凭据显式保存；配置可导出为 JSON 并通过剪贴板迁移。任务中心集中展示待同步与失败任务。

数据流水线

从 API 到你的屏幕

文章拉取后进入本地状态、AI 与同步流程。翻译、摘要和过滤拥有独立配置，默认并发数均为 16，而不是共享一个固定上限。

1

拉取

从 Folo API 获取 feeds / social / inbox 三类未读文章

2

本地合并

写入文章库并合并已读覆盖、订阅源与历史状态

3

AI 判定

DeepSeek 给出保留/拒绝建议，被拒文章进入审核队列

4

翻译与摘要

仍未读的文章按配置进入独立后台队列，已读后取消尚未开始的任务

5

审核

横滑或操作菜单审核被拒文章，保留回时间线或移除并标为已读

6

同步

已读状态分批同步到 Folo，失败最多尝试 3 次并保留待同步记录

本地存储

Hive 数据模型

7 个 Hive Box；本地文章库最多保留 5,000 篇，并优先保留未读内容。

ArticleModel
  entryId / feedId / feedTitle / feedImage / title / url / content
  publishedAt / isRead / category / subscriptionCategory / author
  imageUrl / isRejectedByAi / filterReason / filterReviewed / filteredAt

Box: articleDb    — 文章持久化 (limit 5,000)
Box: readStatus   — 已读状态标记 (双向同步源)
Box: setting      — LLM配置 / Token / Filter Prompt
Box: localCache   — 订阅源缓存 (TTL 30min, key: v2)
Box: translations — 翻译记录
Box: summaries    — 摘要记录
Box: readHistory  — 最近阅读与图片缓存清理时间
